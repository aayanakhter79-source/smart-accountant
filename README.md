# 🚀 Zenith IN: DataSnap Pro
**Automating Finance for Creators & Agencies**

DataSnap Pro is an AI-powered tax audit engine designed to convert messy invoices into CA-ready reports in seconds.

### ✨ Key Features:
- **Smart Audit:** Automatic extraction from PDF, PNG, JPG.
- **Forex Logic:** Real-time USD to INR conversion.
- **Tax Compliance:** Auto-detection for GST & TDS (194J).
- **Export:** One-click Excel/Business Report generation.
